# ca_nap_928_feat_6_full_analysis
Full code for shell bead analysis of feature 6 house floor olivella shell beads.
R Project for: Napa Beads: An Interpretation of a Pre-Contact House Floor Feature through Recovered Olivella Shell Beads from CA-NAP-928
Thesis by Gunnar Sippola; 20 April 2026; New Mexico Highlands University

This shell bead analysis uses R for statistical analysis and graphics creation.  each branch contains pieces of each type of analysis. data from feature 6 house floor can be replaced with similarly structured bead data from other sites/features/contexts.  for best results, run script in numerical order.
required packages: readxl, tidyverse, kableExtra, janitor, remotes, tesslle, FactoMineR, factoextra, missMDA, ggpubr, broom, plotly, dplyr, qrcode
